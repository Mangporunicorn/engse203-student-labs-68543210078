# AI Usage

## เครื่องมือที่ใช้
ChatGPT

## ใช้ AI ช่วยเรื่องอะไร
- อธิบายการเชื่อม React กับ Express API
- อธิบายการใช้งาน apiClient และ requestService
- ช่วยอธิบาย Error Handling
- ช่วยอธิบาย Morgan Middleware
- ช่วยวางโครง API Contract
- ช่วยอธิบายและเขียนตัวอย่าง Automated Test ด้วย node:test และ Supertest

## ส่วนที่ตรวจสอบและแก้ไขเอง
- ทดสอบ API จริงด้วย Postman
- ตรวจสอบ Request/Response จริงก่อนเขียน API Contract
- ทดสอบ Frontend เชื่อมต่อ API
- ทดสอบ PUT เปลี่ยนสถานะ
- ทดสอบ CORS และ Error State
- รัน npm test และตรวจผลด้วยตนเอง
